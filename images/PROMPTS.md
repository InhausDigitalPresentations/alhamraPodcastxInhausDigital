# Image prompts — Al Hamra Supper Club Podcast deck

How it works: generate each image in ChatGPT, save it with the exact file name below and drop it into this `images/` folder. The deck picks it up automatically; until then it shows a labelled placeholder. Every image gets a small "Conceptual visualisation" tag on the page.

Generate every image in **landscape 3:2 (1536 × 1024)** except where it says portrait. Save as `.jpg`.

**Paste this style line at the start of every prompt:**

> Photorealistic editorial photograph, shot on 35mm cinema camera, shallow depth of field, warm tungsten and candlelight, soft deep shadows, muted palette of warm blacks, cream, brass and amber with a tiny touch of deep red, Kinfolk / Monocle / Wallpaper* sensibility, quiet luxury, no text, no logos, no brand names, no watermarks.

In the soft-focus background, a dining table with candles. No visible cables, no crew. Feels discreet, architectural, intentional.
